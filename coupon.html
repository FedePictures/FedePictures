Gestione coupon FedePictures

Questo è il file centrale dei coupon dello Shop. Per creare una promozione, modifica soltanto il blocco JSON qui sotto e pubblica il file su GitHub.

  1. active: true attiva il coupon; false lo disattiva.
  2. type: "fixed" applica uno sconto fisso in euro.
  3. type: "percent" applica uno sconto percentuale sul subtotale dei prodotti.
  4. value indica l'importo o la percentuale.
  5. expiresAt indica la scadenza in formato ISO; usa null per nessuna scadenza.

Nota: questo file si trova sul sito pubblico. I codici inseriti qui possono essere letti da chiunque apra il file. Inserisci soltanto coupon che sei disposta a rendere visibili.

Esempi da copiare quando vorrai creare i primi coupon:

"FEDE10": {
  "active": true,
  "type": "fixed",
  "value": 10,
  "label": "10 € di sconto",
  "expiresAt": null
},
"WELCOME15": {
  "active": true,
  "type": "percent",
  "value": 15,
  "label": "15% di sconto",
  "expiresAt": "2026-12-31T23:59:59+01:00"
}

Ogni coupon può essere usato una sola volta per indirizzo email. La verifica effettiva viene eseguita dal sistema ordini, non soltanto dal browser.
